# Пояснювальна записка — Довідник абітурієнта (ООП)

Генератор пояснювальної записки курсової роботи у форматі DOCX за ДСТУ 3008.
Сама програма — у репозиторії `oop-coursework`.

## Генерація

```bash
pnpm install
pnpm report        # → 2026_ПІ_ООП_ПЗПІ-25-6_Коновалов_О_О.docx
```

## Перерахунок номерів сторінок у змісті

```bash
pnpm update-toc    # міряє сторінки з PDF і оновлює content/toc-data.mjs
```

## Структура

- `generate-report.mjs` — складання документа (docx-js)
- `content/` — текст розділів і дані (вступ, сценарії, функції, проєктування, висновки, джерела, зміст)
- `sketches/` — ескізи інтерфейсу (рисунки 1.1–1.5)
- `uml/` — діаграма класів (рисунок 2.1)
